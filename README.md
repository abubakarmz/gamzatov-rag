# Помощник по творчеству Расула Гамзатова (RAG)

Проект для конференции «Шаг в будущее». Тема исследования: **можно ли доверять
нейросети вопросы о Расуле Гамзатове и помогает ли ей «библиотека» источников (RAG)**.

## Что внутри

| Файл / папка | Что это |
|---|---|
| `config.py` | все настройки: источники, модели, размер карточек |
| `step1_collect.py` | сбор данных: парсит статьи Википедии и Викицитатника → `data/raw/` |
| `step2_split.py` | нарезает статьи на карточки → `data/chunks.json` |
| `rag.py` | поиск карточек (3 способа) и запрос к нейросети |
| `step3_ask.py` | помощник в консоли |
| `app.py` | помощник в браузере (для защиты) |
| `step4_experiments.py` | три эксперимента, таблицы и графики |
| `research/questions.json` | 50 вопросов с правильными ответами (45 фактических + 5 ловушек) |
| `research/results/` | результаты экспериментов (CSV) |
| `research/charts/` | графики |
| `docs/` | PDF исследовательской работы (создаётся скриптом `make_docs.py`) |

## Как запустить

1. Установить [Python 3.11](https://www.python.org/) и [Ollama](https://ollama.com/).
2. Скачать нейросети:
   ```bash
   ollama pull qwen2.5:1.5b
   ```
   ```bash
   ollama pull llama3.2:3b
   ```
3. Установить библиотеки:
   ```bash
   pip install -r requirements.txt
   ```
4. Собрать данные и нарезать их (уже сделано, результат лежит в `data/`):
   ```bash
   python step1_collect.py
   ```
   ```bash
   python step2_split.py
   ```
5. Задать вопрос в браузере:
   ```bash
   streamlit run app.py
   ```
6. Повторить эксперименты (долго, 1–2 часа на слабом ноутбуке):
   ```bash
   python step4_experiments.py
   ```

Тексты взяты из Википедии и Викицитатника (лицензия CC BY-SA 4.0).
