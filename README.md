# Помощник по творчеству Расула Гамзатова (RAG)

Проект для конференции «Шаг в будущее». Тема исследования: **может ли нейросеть отвечать
на вопросы о Расуле Гамзатове без выдумок и помогает ли ей «библиотека» источников (RAG)**.

## Результат

Одна и та же нейросеть (qwen2.5:1.5b) ответила на 45 вопросов о Гамзатове:

| Режим | Верно | Выдумано |
|---|---|---|
| Без библиотеки | 1 из 45 | 44 |
| С библиотекой (RAG) | 35 из 45 (78%) | 9 |

## Что внутри

| Файл / папка | Что это |
|---|---|
| `Презентация.pptx`, `Презентация.pdf` | презентация к защите |
| `docs/Исследовательская_работа.pdf` | текст исследовательской работы |
| `config.py` | все настройки: источники, модель, размер карточек |
| `step1_collect.py` | сбор данных: парсит статьи Википедии и Викицитатника → `data/raw/` |
| `step2_split.py` | нарезает статьи на карточки → `data/chunks.json` |
| `rag.py` | поиск карточек (BM25) и запрос к нейросети |
| `app.py` | помощник в браузере (для демонстрации) |
| `step3_ask.py` | помощник в консоли |
| `step4_experiments.py` | эксперименты, таблицы и графики |
| `make_docs.py` | собирает PDF исследовательской работы |
| `research/questions.json` | 50 вопросов с правильными ответами (45 фактических + 5 ловушек) |
| `research/results/` | все ответы нейросети и итоговые таблицы (CSV) |
| `research/charts/` | графики |

## Как запустить

Нужен обычный ноутбук (8 ГБ памяти), интернет не нужен.

1. Установить [Python 3.11](https://www.python.org/) и [Ollama](https://ollama.com/).
2. Скачать нейросеть (около 1 ГБ):
   ```bash
   ollama pull qwen2.5:1.5b
   ```
3. Установить библиотеки:
   ```bash
   pip install -r requirements.txt
   ```
4. Открыть помощника в браузере:
   ```bash
   streamlit run app.py
   ```

Данные уже собраны и лежат в `data/`. Чтобы собрать их заново: `python step1_collect.py`,
затем `python step2_split.py`. Повторить эксперименты: `python step4_experiments.py`
(около получаса).

Тексты взяты из Википедии и Викицитатника (лицензия CC BY-SA 4.0).
